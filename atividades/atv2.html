Para montar ambiente de programação do zero, você vai precisa de algums itens básicos e seguir algumas etapas simples.

  • Computador com acesso à internet
  • Editor de códigos (ex: VS Code)
  • navegador atualizado
  • Git instalado
  1. Baixe e instale o editor de código
  2. instale o Git e configure seu usuário
  3. Crie uma pasta para seus projetos
  4. Abra o editor e comece a codar
